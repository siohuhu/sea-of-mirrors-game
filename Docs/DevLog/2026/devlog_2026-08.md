## 2026-08-14　🤖 機器人造型：概念稿 3、4 整合設計 ＋ 伴寵存在論分類 ＋ 移動方式地形敘事框架

### 概念稿 3、4 整合設計

概念稿 3 將麥金塔款與錫人款元素融合成新造型：
- **取自麥金塔款**：方正箱型身體、斜切頂角、身體中段水平分割線、方形面板（同時承接軟碟輸入／靈魂收納雙重機能）
- **取自錫人款**：圓形發光眼睛（鹵素燈）、鉚釘細節、偏冷藍灰單色金屬質感
- **新增**：側面橫紋通風口，兩版都沒有的細節，暗示「機械運轉」說服力，呼應「記憶體」「延遲」設定
- 足部比例介於兩版之間

**情感邏輯**：因保留發光圓眼，偏向麥金塔款「主動表達」一點，但整體氣質不失錫人款沉穩踏實——不必在「文學精神 vs 機制成熟度」二選一，雙面優點可保留。

**身高定案**：60–75 公分（延續麥金塔款區間，不採錫人款 110–130 公分）。

**旅人身高基準（新增數值）**：153–163 公分。小土豆體高約為旅人的 40–48%，比例接近及腰到及胸之間，符合寵物型夥伴尺度感，可作為五隻伴寵尺寸對照基準線。

**概念稿 4 腿部演化**：概念稿 3 內縮直立雙腿 → 概念稿 4 外移分開雙腿 → v4.2 修正成單一寬底座＋細支撐柱（利於滑行動畫）→ 正面稿確認雙腿對稱（側面不對稱感為透視效果，非實際設計）。

**移動方式定案：滑行**，非行走。呼應「笨拙但可靠」核心人格，也避開短胖比例角色實作行走動畫容易顯得突兀的問題。

**支點轉動機制（新增）**：腿與身體連接處作為支點，上半身可以此為軸心傾轉角度（如向上看），回應旅人/環境。手繪圖證實傾斜幅度可達 30–40 度，足部貼地不動、僅上半身傾斜，是一個以腿部關節為軸心的剛體傾斜動作，非多關節彎曲。因沒有頸部關節（方正一體成形頭身結構），支點傾轉是「無頸部旋轉」限制下的替代解法。

**雙軌反應系統**：眼睛燈光明暗表達「內在狀態」，支點傾轉姿態表達「外在注意力/在乎什麼」，兩者可組合使用（如旅人靠近時緩慢傾轉向上看向旅人，同時搭配眼睛燈光漸亮）。

**滑行與支點轉動的分工建議**：滑行時身體維持固定角度前進，停下後才觸發支點轉動回應旅人/環境——「移動狀態」與「互動狀態」分開，避免兩種動作疊加時顯得混亂或機械故障感（與「可靠」人格衝突）。

### 伴寵存在論分類框架（新增）

**背景**：小土豆（機器人）確認為「某位旅人製作、留在鏡之海裡」——以此為契機，伴寵分類方式不再只是元素屬性，新增一層**存在方式的分野**：

- **被創造型**（目前確認：機器人・小土豆）——由某位旅人親手製作，承載那位旅人的意念/技藝/情感投射，本質上更接近「被賦予靈魂的器物」
- **自然存在型**（暫定：狐、狼、貓頭鷹）——鏡之海世界本身自然孕育的生命，不依附任何特定旅人的創造行為而存在

**對存在論不只是背景裝飾，實質影響情感邏輯**：被創造的伴寵天生帶著「被留下」「被交託」的孤獨感與使命感；自然存在的伴寵則更像是鏡之海本身的一部分，安靜地等待被發現。

**與同行足跡機制的本質連結**：小土豆本身就是一份同行足跡——從被動的訊息/碎片，升級成一個會自己走下去、繼續陪伴新旅人的完整生命體。玩家亦是「某一位旅人」，玩家在遊戲中的存在本身（探索、命名、關係深化）終將成為未來某個時刻的同行足跡，與移動哲學「留下痕跡」、Vision 願景「心靈鏡像」呼應同一精神在不同尺度上的展現。

**命名系統的進一步呼應**：小土豆可能連創造者的存在都逐漸模糊（記憶體不足），直到新旅人（玩家）出現、重新命名，才又有了新的意義依附——命名不只是「承接關係」，也可解讀為「傳承」。

**待辦**：
- [ ] 創造者旅人是否需要具體化（完全隱藏於設計筆記 vs. 透過碎片/日記逐漸拼湊給玩家），待 Zhen 決定
- [ ] 狐/狼/貓頭鷹是否同樣使用自然存在型分類，或各自有不同存在邏輯，待後續補充背景描述時一併確認

### 伴寵移動方式與地形敘事系統框架（新增）

**核心思路**：移動方式不只是動畫技術選擇，而是個性表達的一部分——五隻伴寵應各自有對應個性的移動邏輯，讓玩家光看動態就能分辨角色、感受性格差異，而非統一套用通用移動邏輯。

**五隻伴寵移動方式草案（待實體化，直接推自現有個性初稿）**：
- 🦊 狐・火（被光吸引也帶光）——跳躍感，忽快忽慢，像被什麼吸引突然衝出去
- 🐺 狼・水（感知流動與水共生）——流暢連貫、貼地滑行式奔跑，重心低而穩
- 🦉 貓頭鷹・風（捕捉風息翱翔天際）——飛行/滑翔為主，落地動作乾脆利落
- 🤖 機器人・土（記憶延遲但可靠）——**滑行，已定案**，笨拙但穩定

**土與水的差異提醒**：狼（貼地滑行）與機器人（滑行）都屬「貼地平移」大類，需在動態質感上做出差異（狼是有機流動的滑順，機器人是機械感的平移），避免兩者看起來太相似。

**地形設計也是一個敘事**：地形不只是移動的舊台背景，而是承載敘事意義的一部分（例：碎石地可能是某段記憶的遺跡，潮滑苔地特別考驗狼的移動、卻是貓頭鷹的天堂）。不同地形對不同伴寵移動方式的適應度差異，可以自然成為角色性格側寫的機會，而非需被工程解決掉的缺陷——例如小土豆滑行遇到崎嶇地形時可能露出一點笨拙、需旅人幫忙或繞路，反而加深「他很努力但有限制、但依然可靠」的核心人格。

**待辦**：
- [ ] 狐/狼/貓頭鷹移動方式草案正式確認
- [ ] 地形分類與對應敘事意義規劃（後續世界地圖設計階段進行）
- [ ] 五隻伴寵移動動畫優先度排序

## 2026-08-13　🔄 Core Loop 核心閉環結構定案（v04_3_1）

**三種節點性質，取代原本連續編號（1–6）**：
1. **可重複執行的步驟**（Walk/Stop/Touch/Listen）——保留編號，分鐘級單輪閉環
2. **隨時可能觸發的關係節點**（伴寵締結・反饋/命名/關係深化）——降層級為節點、拿掉編號，因為它是四動作閉環持續運作時隨時可能發生的累積性互動，非排隊等候的階段性步驟
3. **不同時間尺度的背景循環**（月神卡凝視、月相・世界流動）——拿掉編號，因兩者分屬「並行疊加機制」與「28天週期的另一尺度循環」，皆非與 1–4 同順序、同顆粒度的步驟

**判斷依據**：原本連續編號會讓人誤以為所有節點同屬同一時間顆粒度，混淆了分鐘級與月級兩種循環。拿掉編號修正表達上的潛在誤導，因果箭頭與連接文字（推動世界運轉／世界產生回應）完整保留，不影響機制完整性。

**用詞微調**：
- 「28天月相/世界改變」→「月相・世界流動」（呼應 World Flow 字義）
- 「獲得：記憶碎片/寫入手帳」→「記憶碎片・與旅人留下的記憶相遇」（呼應同行足跡設定）
- 「伴寵締結/手帳記錄（Taming & Journal）」→「伴寵締結（反饋/命名/關係深化）」（去英文機制詞，補上 warmth 長期累積概念）

已同步更新「🌍 World Flow 骨架」頁面 Core Loop 小節，並修正先前記錄中「伴寵締結」誤植的用字。

**手稿溯源**：本次定案的三版流程圖（v03→v04_2→v04_3_1）源自紙本手繪草圖，記錄了 Core Loop 從「World Flow → Experience Flow → Walk/Stop/Touch/Listen」的初步構想，以及關鍵靈感筆記「What if exploring was simply... Taming and Journal」——探索＝馴服＋日記的核心洞察，是伴寵締結機制與 Core Loop 整合的最初起點。

**待辦**：圖中「小箱型車」統一改為「小箱車」（與 World Flow 骨架頁面供給邏輯統一）✅ 已完成。

**概念稿 1・麥金塔電腦款**：方正機身＋螢幕臉，黃綠藍手繪配色，呼應土元素正方形符號定案。設有軟碟槽讀取碎片資料，記憶體不足反應延遲（螢幕像素雜訊＋READING... 提示），但依然可靠。暫名「小土豆」，已建立對話範例作為之後設計基準。

**概念稿 2・錫人款**：錫與鋁合金材質，鉚釘拼接工藝感，發想自復古錫玩具與《大都會》機器人蒂瑪（Tima）。胸口方形蓋子內裝「獨一無二的靈魂」，同時可收納礦石與碎片，屬實體珍藏邏輯。身高 110–130 公分。表情設定為疏離、被動投射型，參照《浩劫重生》排球「威爾森」——情感由旅人自行投射，非角色主動表達，與 Vision「心靈鏡像」命題高度貼合。

**概念稿 2 頭部修正**：原黑點眼睛表情過於疏離，改為內嵌可變化鹵素燈，緩慢明暗變化對應互動延遲，短路閃爍對應碎片收藏反應，情感基調仍維持「慢但可靠」。

**兩版對照結論**：本質一致（土元素／可靠／記憶延遲），但情感傳遞方向相反——麥金塔款主動表達，錫人款被動投射。屬於「文學精神 vs. 機制成熟度」的取捨，尚未定案，後續由概念稿 3、4 整合方向推進（見 8/14 條目）。
