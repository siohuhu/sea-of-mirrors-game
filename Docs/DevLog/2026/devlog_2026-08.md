## 2026-08-19　🏗️ Technical Architecture v0.1.3.1 檢查與用詞修正

在 System Flow（SYS-A/B/C）基礎上，這版擴充了完整技術閉環：新增 **Outputs（輸出層）**（世界回應分流至場景與氛圍／動態遭遇：小箱車或殘影／聽覺語境三種輸出）與 **Persistence/Data Layer（持久化層）**（Local State/Cache、SavePoint/Snapshot、Companion Registry、World State DB），與 8/3 已定案的 Firebase/Game Center 技術方案路徑一致。

**用詞修正**：Outputs 輸出層原註解「世界回應的多模態表現」改為「世界回應的多感官回饋」——「多模態」屬學術/工程語境詞彙，與專案一貫的去技術化、詩意包裝語感不符，「多感官回饋」語意相同但更易懂、也更貼近既有感官體驗用詞習慣。待套用至圖面下一版。

**REV 節點補充註解**：確認「REV」為 Return / Echo / Variation 三字首縮寫（純簡寫命名，非逐字對應下方「探索留痕/記憶回拆/狀態養分」三個關鍵詞，兩者獨立）。REV 是 Outputs 三節點匯聚後的回流節點，將輸出內容回饋進 SYS-B 循環或 SYS-A 世界狀態，形成「世界回應玩家→回流養分→影響下一輪世界狀態」的閉環。待補上正式圖面註解。

**手稿溯源（202608_TechArch_v0.1.1_Draft）**：Technical Architecture 最初手繪草稿確認，REV（Return/Echo/Variation）與「多模態」用詞均於此階段已存在。值得注意的是，手稿上原本寫的是「多模態．(sensory multimode) outputs」，括號內已經注記了「sensory」（感官）這個更貼近體感的英文詞，只是後來畫成正式圖表時，中文用詞簡化成了「多模態」。因此本次「多感官回饋」的修正，實質上是回歸最初手稿裡就有的感官語感，修正有脈絡依據，非憑空的新方向。

**檢查結果**：月相矩陣天數對應、小箱車用詞、SYS-B 內部決策點註解，皆與現有設定一致，無星座相關用詞。

## 2026-08-14　🤖 機器人造型：概念稿 3、4 整合設計 ＋ 伴寵存在論分類 ＋ 移動方式地形敘事框架

### 概念稿 3、4 整合設計

概念稿 3 將麥金塔款與錫人款元素融合：方正箱型身體、方形面板（軟碟輸入／靈魂收納雙重機能）取自麥金塔款；圓形發光眼睛（鹵素燈）、鉚釘細節、偏冷藍灰單色金屬質感取自錫人款；新增側面橫紋通風口。身高定案 60–75 公分。**旅人身高基準（新增數值）：153–163 公分**，小土豆約為旅人身高 40–48%。

概念稿 4 腿部歷經內縮直立→外移分開→v4.2 單一寬底座＋細支撐柱（利於滑行動畫）→正面稿確認雙腿對稱。**移動方式定案：滑行**，呼應「笨拙但可靠」核心人格。

**支點轉動機制（新增）**：腿與身體連接處作為支點，上半身可傾轉角度回應旅人（手繪證實傾斜幅度達 30–40 度，足部貼地不動）。因無頸部關節，此為替代解法。雙軌反應系統：眼睛燈光表達內在狀態，支點傾轉姿態表達外在注意力。滑行（移動狀態）與支點轉動（互動狀態）建議分開觸發。

### 伴寵存在論分類框架（新增）

小土豆確認為「某位旅人製作、留在鏡之海裡」——伴寵分類新增存在方式分野：
- **被創造型**（機器人・小土豆）——承載創造者旅人的意念/技藝/情感投射
- **自然存在型**（暫定：狐、狼、貓頭鷹）——鏡之海世界本身自然孕育

小土豆本身即是「同行足跡」的具體化，命名系統也因此多一層「傳承」的解讀。

### 伴寵移動方式與地形敘事系統框架（新增）

移動方式定位為個性表達的一部分。五隻伴寵移動方式草案：狐/火（跳躍感）、狼/水（貼地滑行式奔跑）、貓頭鷹/風（飛行/滑翔）、機器人/土（滑行，已定案）。狼與機器人皆屬「貼地平移」，需在動態質感上做出差異。地形設計本身也是敘事的一部分，不同地形對不同伴寵移動方式的適應度差異，可作為角色性格側寫的機會。

## 2026-08-13　🔄 Core Loop 核心閉環結構定案（v04_3_1）

**三種節點性質，取代原本連續編號（1–6）**：
1. **可重複執行的步驟**（Walk/Stop/Touch/Listen）——保留編號
2. **隨時可能觸發的關係節點**（伴寵締結・反饋/命名/關係深化）——降層級為節點、拿掉編號
3. **不同時間尺度的背景循環**（月神卡凝視、月相・世界流動）——拿掉編號

**用詞微調**：「28天月相/世界改變」→「月相・世界流動」；「獲得：記憶碎片/寫入手帳」→「記憶碎片・與旅人留下的記憶相遇」；「伴寵締結/手帳記錄（Taming & Journal）」→「伴寵締結（反饋/命名/關係深化）」。
