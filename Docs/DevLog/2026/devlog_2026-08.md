## 2. FTUE 第 2 頁詳細流程圖：微光記憶觸發機制（2026-08-03）

**文件**：`FTUE_專屬詳細流程圖___微光記憶觸發機制.png`（User Flow 第 2 頁）

### 核心邏輯：兩條路徑

**路徑 A：已有 Game Center 身份的玩家**
社群分享、流浪商人交易、換新裝置三個動作皆靜默寫入雲端（Cloud Token／SavePoint／自動讀取），不跳出任何登入畫面——因多數 iOS 玩家系統層級已登入 Game Center，`GKLocalPlayer` 驗證本身即為靜默。解答先前疑問：社群分享與流浪商人交易不需要額外要求玩家做登入動作。

**路徑 B：離線／未登入玩家**
設計「微光記憶」兩階段漸進式軟性引導：
- 第一階段（伴寵帶回）：僅 UI 邊角提示文字，不打斷、不強迫
- 第二階段（凝視任務完成／今日核心體驗 Peak Moment）：情緒最高點時才引導連結

此設計選在**情緒高點**而非**功能需要**時才觸發登入引導，延續先前「先建立情境再談系統」的設計邏輯（呼應 Tiny Echo 案例），並更進一步將「觸發時機」也用情緒節奏設計，而非技術節奏。

### ⚠️ 待確認事項（Zhen 自行思考確認中）

1. **「觸發點3：跨裝置同步」措辭疑似矛盾**：文字寫「靜默感知...跳出喚醒提示」，靜默與跳出提示邏輯上有落差。推測實際意圖為「偵測過程靜默，偵測到雲端存檔時才跳出『歡迎回來，要還原旅程嗎』提示」，建議未來實作前文字表述需更明確，避免工程師誤解為完全不能有任何 UI
