# 🪐 Sea of Mirrors 開發日誌 — 2026/10

## 📅 2026-10-09｜Unity 軸心工具開發：CustomPivotTool・QuickTreePivotTool・CustomPivotWrapperMarker

### 1. 用途
- 作用於**樹、物件，以及任何需要調整軸心的 3D 物件**（例如 Tree、House、Cube）。
- 不修改 Mesh 資產本身：工具會建立一個空的 **Pivot Wrapper**（物件名稱 `{物件名}_Pivot`）包住模型，由 Wrapper 的位置當作新的軸心。
- 所有操作皆可用 Cmd + Z（Mac）／Ctrl + Z（PC）復原。

### 2. 三支腳本

| 腳本 | 類型 | 選單位置 | 用途 |
|---|---|---|---|
| `CustomPivotTool.cs` | Editor 視窗 | Tools → Siohuhu → 自訂軸心與歸零工具 | 單一物件的軸心設定：快速預設對齊、手動拖曳／數值微調、歸零 |
| `QuickTreePivotTool.cs` | Editor 視窗 | Tools → Siohuhu → ＊＿＊樹木底部軸心與歸零 | 樹木／植物專用，**可多選批量**，一鍵設定底部軸心並歸零 |
| `CustomPivotWrapperMarker.cs` | MonoBehaviour（空元件） | — | 標記哪些物件是 Pivot Wrapper，沒有任何執行期邏輯 |

**CustomPivotTool 主要功能**
- 啟用／停用開關（可停用並關閉視窗，不會控制新選取的物件）。
- 「快速預設對齊」：Center、Bottom_Y、Top_Y、Left_X、Right_X、Back_Z、Front_Z。
- 「初始化底部軸心」：重置 Offset 並套用 Bottom_Y，一鍵完成。
- 「手動拖曳／數值微調」：Scene 內紅／綠／藍箭頭拖曳，或輸入 Offset 數值，確認後才套用；可選擇是否隱藏 Unity 原生 Move Tool。
- 歸零選項：
  - **底部軸心歸 0（Y 向上）**：先把 Pivot 設在整個資產最低點，再把 Pivot 移到世界原點。
  - **中心軸歸 0**：先把 Pivot 設在整個資產中心，再把 Pivot 移到世界原點。
  - **只移動目前軸心到世界原點**。

**QuickTreePivotTool**
- 一個按鈕「一鍵設定底部軸心並歸零」：軸心對齊底部（-Y），並把世界座標與旋轉歸零（0, 0, 0）。
- 支援同時選取多個物件批量處理。

### 3. 作業流程
1. 美術在 Blender／Maya 建立物件並匯出
2. Unity 成員匯入 FBX
3. 在 Hierarchy 選取物件（例如 Tree、House、Cube）
4. 開啟 CustomPivotTool
5. 按「初始化底部軸心」
6. 需要時手動微調
7. 按「底部軸心歸 0（Y 向上）」
8. 儲存 Scene 或 Prefab
9. 將 `.prefab`、Scene 與工具腳本一起提交版本控制

### 4. 放置位置與版本控制
- `CustomPivotWrapperMarker.cs` 必須放在**非 Editor** 資料夾（建議 `Assets/Scripts`），且檔名必須與類別名稱一致；放進 Editor 資料夾或寫在別的檔案裡，場景中的 Marker 會變成 Missing Script。
- 兩支 Editor 工具建議放在 `Assets/Scripts/Editor/`。
- Sandbox 的 `.gitignore` 與備份腳本只保留 `Assets/Scripts`、`Scenes`、`Prefabs`（與必要設定），放在其他資料夾（例如 `Assets/Editor`）的工具腳本**不會被備份**。

### 5. 注意事項
- **QuickTreePivotTool 會把處理過的物件移到世界原點並歸零旋轉**。多個物件同時處理會全部疊在原點，適合用來製作 Prefab 資產；**不要對已經擺放在場景中的物件使用**。
- 兩支工具目前以物件本地座標計算「底部」。若匯入的 FBX 根物件帶有旋轉（例如 -90°），底部可能不是世界最低點（尚未實測，待確認）。
- 選取的若是 Prefab 實例內部的子物件，Unity 不允許更換父層；請改選最外層根物件，或先 Unpack。

### 6. 協同注意事項
1. `CustomPivotTool.cs` 專案內只放一份，放在 `Assets/Scripts/Editor/`。
2. `CustomPivotWrapperMarker.cs` 放在非 Editor 資料夾（例如 `Assets/Scripts`），檔名須與類別名稱一致。
3. 調整完成後，儲存 Scene，或把 Pivot Wrapper（連同模型）儲存成 Prefab。
4. FBX 重新匯入後，Wrapper 不會被刪除，但軸心位置不會自動更新；模型尺寸或形狀有變時，需確認軸心是否仍在底部。
5. 工具不用時，取消「啟用 CustomPivotTool」或關閉視窗，就不會對選取的物件顯示手把，也不會自動建立或修改任何物件。
6. 工具本身只在編輯器運作，不會進入遊戲；已建立的 Wrapper 與 Marker 會以一般空物件存在於場景中。
7. 分工：美術負責模型（FBX），Unity 成員負責 Pivot 與 Prefab 整理；工具不修改原始 Mesh，兩邊不會互相覆蓋。
