## 1. 角色移動速度規格（2026-07-01）

### 移動速度設定

| 狀態 | 速度值 | 備註 |
|---|---|---|
| 走路 | 2.0 | 基本移動，符合「走→停→摸→聽」的閱讀節奏 |
| 快走 | 3.5 | 中間過渡 |
| 奔跑 | 5.5 | 最高速度 |

### 技術規則
- 動畫播放速度必須與移動速度同步
- 移動速率改變時，走路動畫幀率需對應調整，避免「滑行」感
- 實作方式：Unity Animator 中將動畫 Speed 與移動速度公式綁定

### 與移動哲學的關係
- 走路（2.0）是主要狀態，對應「走→停→摸→聽」的感官漫遊節奏
- 奔跑（5.5）不是核心體驗，屬於特殊狀態

## 4. 視角設定（2026-07-02）

### 畫面設定
- 畫面裡沒有玩家角色，只有伴寵
- 玩家視角 = 旅人本身（鏡頭就是玩家的眼睛）
- 伴寵「回頭看」時，它看的是玩家本人，不是代理角色
- 連「主角」都消失了，世界更安靜，符合無聲敘事原則

### 移動控制
- 麵包屑系統（暫定）：玩家丟出投躑物指引探索方向
- 投躑物跟伴寵喜好和收集物件直接連動

## 5. 伴寵互動系統（Tiny Echo + 投躑合併方案）（2026-07-02）

### 核心設計

**主軸：Tiny Echo 方向（自由陪伴）**
```
玩家主動探索世界
  └── 伴寵在旁邊自由玩耍
        ├── 有時跑到玩家前面
        ├── 有時在後面自己玩
        └── 玩家不需要一直管理它，但一直感覺到它在
```

**輔助：投躑作為「邀請」而非指令**
```
玩家丟出收集到的物件
  └── 伴寵往那個方向跑過去玩
        └── 順便帶玩家往那個方向走
              （是邀請，不是控制）
```

---

### 四隻伴寵喜好物件（初稿）

| 伴寵 | 元素 | 推測喜好投躑物 |
|---|---|---|
| 狐 | 火 | 發光的東西・溫暖的物件 |
| 狼 | 水 | 水邊的東西・光滑石子・貝殼 |
| 貓頭鷹 | 風 | 輕盈的東西・羽毛・乾燥葉子 |
| 機器人 | 土 | 礦石・金屬碎片・堅硬的東西 |

白鹿不在此系統（機制層，不是玩家伴寵）。

---

### 溫度系統

**玩家給伴寵喜歡的物件玩 → 溫度增加**

溫度顯示方式：**隱性，不顯示數值**
- 溫度高：伴寵主動靠近・在玩家腳邊打滾・反應更活潑
- 溫度低：伴寵離玩家遠一點・自己玩自己的
- 伴寵的行為本身就是溫度的指標，不破壞氛圍

**溫度影響每日帶回來的東西：**
- 影響的是「意外性」，不是「稀有度」
- 溫度高 → 帶回來的東西更奇特、更有故事性（但不一定「更好」）
- 溫度低 → 帶回來的東西比較一般
- 刻意避免「刷溫度換好物品」的功利動機，保留繫伴的情感重量

---

### 投躑物件邏輯

```
玩家收集物件
  └── 可以投躑（邀請伴寵往某方向走）
        └── 伴寵反應取決於物件是否符合喜好
              ├── 喜歡 → 開心跑過去玩 → 溫度增加
              └── 不喜歡 → 還是過去，但興趣缺缺 → 溫度不變或微降
```

投躑物丟出後會消失（跟同行足跡一樣，當下的互動，不留存）。

---

### 與整體設計的連動

| 系統 | 關係 |
|---|---|
| 移動哲學（走→停→摸→聽）| 玩家主動探索，投躑是「摸」的延伸 |
| 收集系統 | 收集是為了自己（日記）也為了伴寵（投躑）|
| 每日帶回禮物 | 溫度決定今天帶回東西的意外性 |
| 無聲敘事原則 | 溫度隱性顯示，伴寵行為就是語言 |
| 輕量溫暖原則 | 投躑是選擇性動作，不丟也能完成今天 |

### 確認細節（2026-07-02）

**1. 四隻伴寵喜好物件（暫定，待收集系統確立後對齊）**

| 伴寵 | 元素 | 喜好物件方向 |
|---|---|---|
| 狐 | 火 | 發光物・溫暖物・火焰相關 |
| 狼 | 水 | 光滑石子・貝殼・水草・水邊物件 |
| 貓頭鷹 | 風 | 羽毛・乾燥葉子・輕盈物件 |
| 機器人 | 土 | 礦石・金屬碎片・堅硬物件・遺跡碎片 |

**2. 溫度重置機制：每週重置**
- 每週新的開始，溫度歸零
- 不會因為上週缺席而永遠冷淡，也不會產生「不敢不登入」的壓力
- 七天是自然的心理週期，符合輕量溫暖原則

**3. 投躑觸發方式：從日記選出物品**
- 不是隨手一直丟，而是主動進入日記，挑選今天要給伴寵的東西
- 選擇本身是一個儀式感的小動作，跟日記整理的節奏吻合
- 自然避免「瘋狂丟東西刷溫度」的行為

**4. 伴寵溫度行為邊界：熱情 vs 平淡**

| 溫度狀態 | 伴寵行為表現 |
|---|---|
| 高溫度（熱情）| 主動靠近・在玩家旁打滾・反應活潑・帶回有趣的東西 |
| 低溫度（平淡）| 離玩家遠一點・自己玩自己的・帶回普通的東西 |

邊界原則：
- 低溫度時伴寵**不表現出負面情緒**（不難過、不生氣），只是平靜、自在
- 避免讓玩家感到愧疚或壓力，不能讓「不給東西」變成一種懲罰
- 刻意不做「不開心」，只有「熱情」和「平淡」兩種狀態

## 6. 首次登入・元素屬性決定機制（2026-07-03）

### 設計原則
不收集個資（生日・血型），但讓玩家有「被理解」的感覺。
元素屬性由世界決定，不是玩家「選擇」伴寵——符合繫伴哲學：**是它選擇你，不是你選擇它。**

---

### 評估方向

**方向 A：塔羅牌選擇**
- 玩家從幾張牌面朝下的塔羅牌中選一張
- 翻開 → 顯示牌的意象與短文 → 決定元素屬性 → 對應伴寵出現
- 符合世界觀，結果由牌決定，玩家不是在「挑寵物」

**方向 B：感官題測驗（輕量版）**
- 3－5 個感官選擇題（篝火的光 vs 雨後的氣味）
- 不問個人資料，只問感受
- 與現有 sea-of-mirrors 旅人原型測驗邏輯相似

**方向 C：世界觀情境選擇**
- 「霧中，你看見了什麼？」
- 完全在世界觀內，沒有「測驗」的感覺
- 像是第一次踏進世界時自然發生的事

---

### 確認方向：三張牌選一（命運儀式）

```
第一次進入鏡之海
  └── 霧中浮現三張牌面朝下的牌
        └── 玩家選一張（不知道是什麼）
              └── 牌翻開
                    └── 短文出現（玩家自行解讀）
                          └── 伴寵從霧裡走出來
                                └── 這就是你的伴寵，從今天起
```

**設計哲學：**
- 玩家「選」了，但不知道選的是什麼——結果還是命運
- 選擇是直覺帶去的，跟塔羅牌占卜邏輯完全一致
- 三張剛好：有參與感但不複雜，不讓玩家猶豫太久
- 類似哈利波特魔法帽——不是你選學院，是帽子看見你
- 玩家用心理填充「為什麼是它」，符合無聲敘事原則
