旅人碎片與月神卡（2026-07-13）第二版
鏡之海中，旅人走過的地方會留下碎片。
 那是記憶的殘影，也是故事的痕跡。
 大多數碎片沉睡在霧裡，無人知曉。
 只有少數，在月光照耀的時刻甦醒，化為**月神卡**。
 
旅人在鏡之海留下了許多碎片，
其中少數會在月光照耀下甦醒，化為月神卡。
當你凝視它們時，世界便會留下一段低語。
月神卡：其中一種具有特殊力量的碎片，是用來進行「世界的低語」的媒介。
旅人碎片：玩家收集的整體收藏系統，每一片都是一位旅人的記憶或故事。
----------------------------------------------------------

系統定義

旅人碎片
玩家在鏡之海探索、收集的整體收藏系統。
每一片碎片，都是一位旅人的記憶或故事。

月神卡
旅人碎片中具有特殊力量的一種。
是進行「世界的低語」的媒介。
只有在月光照耀的特定時刻，碎片才會甦醒成月神卡。

月亮 → 照耀潮汐 → 產生海霧
海霧 → 沉睡的旅人碎片
月光 → 喚醒碎片 → 化為月神卡
月神卡 → 世界的低語 → 今日低語
月光石 → 遊戲貨幣 → 跟月亮・月神卡同源
