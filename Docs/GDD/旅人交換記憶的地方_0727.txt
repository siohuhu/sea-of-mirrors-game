## 核心世界觀意象對照表
| 元素名稱 | 它代表什麼 / 象徵與核心意涵 | 在世界的角色與作用 |
| :--- | :--- | :--- |
| **海霧** | 未被發現的記憶 | 覆蓋潛意識的邊界，沉睡著旅人過往的故事。 |
| **月光** | 喚醒與連結 | 照亮海面，將沉睡的記憶碎片喚醒為月神卡。 |
| **碎片** | 旅人留下的痕跡 | 旅人在世界漫遊時落下的記憶殘影與故事。 |
| **鏡面** | 看見自己與他人的記憶 | 心靈的投射，反射出內心未曾整理的角落。 |
| **電話亭** | 記憶交換 | 旅人之間跨越時空與迷霧進行記憶傳遞的場所。 |
| **月光石** | 世界流動的媒介 | 貫穿整個世界觀的能量與交換媒介。 |
